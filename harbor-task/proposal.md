# 任务说明

- **任务标识与版本**：`clearing-core/gateway-cascade-audit` (`v0.3.0`)
- **业务背景与目标**：模拟金融跨境清结算平台在生产峰值期间发生级联延迟与重复扣款事故后的真实 SRE 应急与合规审计闭环。值班工程师需协同使用多套观测与运维系统（Grafana、Perfetto、Gitea、Mailpit、CMDB 拓扑与 SLA 审计控制台），结合本地合同、历史复盘及原始日志，完成“指标归因 → Trace 锁竞争定位 → 代码评审与热修 → 平台实时灰度仿真验证 → 合规变更排期 → 多约束 SLA 赔付核算与邮件回执”全流程交付，沉淀贴近真实企业级排障与跨系统审计的高质量轨迹数据。
- **操作难度与工具类型**：`operation_difficulty = "高级操作"`，`tool_type = "web + cli"`，`difficulty = "困难"`。
- **节点隔离**：结算主调度也会报高延迟。值班工程师须结合调用方向、活跃和预留路径、Grafana 节点曲线的先后关系判断隔离范围，并在控制台核对其余节点的运行状态和变更记录。
