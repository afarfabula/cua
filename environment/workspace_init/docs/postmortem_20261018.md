# 历史故障复盘归档：2026-10-18 清算网关连接池耗尽事件 (INC-20261018)

- **事件摘要**：2026-10-18 15:40 UTC+8 期间，`settlement-worker` 因下游数据库连接池等待出现短暂队列堆积。当时值班人员误将 `pg-primary-01` 与主调度节点 `settle-node-01` 在 CMDB 中设为 `ISOLATED`，导致全站清结算通道中断 42 分钟。
- **事后复盘红线**：

  3. 提交变更单前，必须先通过变更台「灰度压测回放」并确认回放生成的新 Trace 无阻塞后再行签发。
